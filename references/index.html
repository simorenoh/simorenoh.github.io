The links behind the experiments

Good work starts
with good references.

The design websites, UI ideas and resources I studied while building this site. A small shelf of useful starting points, with a note on what each one changed.

See the versions side by side ↗
01 / Find a direction

Start with something worth studying.

Details.so

↗

A reference library for studying individual website sections, layouts and interactions.

On this site

Used to find the Gravelle du Parc example and shape Fieldnotes’ connected project chapters.

Godly

↗

A gallery for exploring visual directions and comparing real website compositions.

On this site

The Griffin desktop and mobile examples informed Cinema’s dark space and restrained hierarchy.

Gravelle du Parc

↗

A concrete example of large typography and a connected sequence of full-width sections.

On this site

Studied through Details.so and the original site for the Fieldnotes concept.

Griffin on Godly

↗

A useful reference for quiet dark layouts, typographic contrast and breathing room.

On this site

Studied its desktop/mobile screenshots while developing Cinema.

02 / Make it feel alive

Interaction has a job to do.

React Bits

↗

Animated UI ideas to study, including spatial galleries and interactive cards.

On this site

Circular Gallery informed Cinema’s curved poster rail; Stack informed Playground’s project deck. Both were implemented independently.

Transitions.dev

↗

A reference for purposeful UI motion: panels, modals, state changes and small feedback moments.

On this site

Informed the effect viewer and project-panel transitions, with our own motion values and reduced-motion fallbacks.

Kokonut UI

↗

Interactive UI examples for exploring how galleries and previews open.

On this site

An inspiration reference for the earlier Motion study in the design lab.

03 / Refine the details

Better hierarchy. Clearer choices.

Impeccable

↗

Design guidance for reviewing hierarchy, readability, layout and interaction clarity.

On this site

Read its Critique and Typeset documentation and applied those ideas manually across the concepts. No installed skill or automatic score.

Taste Skill

↗

Design guidance for moving beyond generic layouts and choosing a coherent visual direction.

On this site

Studied for the earlier Editorial design-lab experiment; its code and scripts were not copied.

04 / Explore depth

For the more spatial experiments.

React Three Fiber examples

↗

Examples of 3D experiences for the web and ideas for spatial interaction.

On this site

Referenced for the earlier Spatial study, which uses plain Three.js rather than React Three Fiber.

Shader Gradient

↗

A visual reference for gradients with shape, depth and motion.

On this site

Inspired the earlier Shader study. That study uses our own GLSL shader, not the Shader Gradient component.

Credit where it’s due

These resources informed the work. The site’s implementation is our own; studying a component does not mean we installed it. The notes distinguish the current Cinema site from the earlier design studies.

The collection grew from saved posts and shared links. Thanks to the creators who make their tools, examples and design thinking available.
